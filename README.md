# Projektöversikt

Det här är en fullstack‑applikation med frontend och backend samt en databas för utveckling.

## Kom igång (översikt)

1. Starta databasen med Docker.
2. Starta backend‑API:t.
3. Starta frontend‑appen.

## Databas

Databasen körs lokalt via Docker och används av backend.

## Backend

Backend är ett .NET Web API med JWT‑autentisering och CRUD‑endpoints.

## Frontend

Frontend är byggd i Angular och använder Bootstrap för styling.

## Miljövariabler

Miljövariabler används för känslig konfiguration (t.ex. databaslösenord).
